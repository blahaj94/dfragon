# MVP 미리보기 자산

- `character.png`, `item-0.png`부터 `item-16.png`: 확정 Penpot 보드에서 가져온 던전앤파이터·네오플 이미지입니다. 이미지 권리는 NEOPLE/NEXON에 있으며 합성 UI 검토를 위한 디자인 자산으로만 사용합니다. 원본 서비스는 https://img-api.neople.co.kr 입니다. 실제 사용자 이름·캐릭터 식별자는 fixture 데이터에 포함하지 않습니다.
- `item-17.png`: NEXON 공식 쇼룸의 임시 발키리 이미지입니다. 원본: https://bbscdn.df.nexon.com/data7/showroom/static/icon/oath_09_valkyrie/00001.png . 실제 서약 종류 매핑을 뜻하지 않습니다.
- `NanumSquareNeo-*.woff2`: NAVER 공식 https://campaign.naver.com/nanumsquare_neo/download/NaverNanumSquareNeo.zip 의 Regular·Bold 원본입니다. 글꼴 저작권은 NAVER·네이버 문화재단에 있으며 OFL 1.1을 따릅니다. 글꼴 자체를 유료 판매하지 않습니다. 전체 라이선스: `FONT-LICENSE`; 출처: https://help.naver.com/support/contents/contents.help?serviceNo=1074&categoryNo=3497 .
- 카메라·상세 열기 SVG는 Lucide 형태를 사용합니다. https://lucide.dev/icons ; `LUCIDE-LICENSE`에 ISC와 Feather 파생 아이콘의 MIT 고지를 보존합니다.

이 자산은 `mvp-preview` 전용 빌드에서만 포함됩니다. 실데이터 소비 시 고정 이미지 origin과 검증한 식별자에서 URL을 구성합니다.
