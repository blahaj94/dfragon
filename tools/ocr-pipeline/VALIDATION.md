2026-09-19 작성. 이 파일은 실제 수행 범위와 수행하지 않은 범위를 구분합니다.

## 수행

- Python 단위·연결 테스트: **77개 통과**.
- Python `compileall`: 통과.
- CLI `--help`: 통과.
- 데이터 snapshot 작성, Unicode 원문 보존, 프로필별 전체 목표 문자 커버리지 확인.
- 데이터 경로 이탈·symlink·이미지 알파·중복·split 간 누출·출력 덮어쓰기 거절.
- 생성한 snapshot의 파일 변경·추가 탐지.
- CTC blank/중복 처리, class 차원·NaN·확률 검사, BGR/정규화/패딩 함수 검사.
- 기존 모델 대비 회귀·문자군별 평가·실제 입력 부재 차단·변환 차이 판정 로직 검사.
- 공식 trainer/export 호출 인자·가중치 checksum·실행 실패·checkpoint 부재 처리 검사.

학습·export·평가 연결 테스트는 명시적인 가짜 실행기와 가짜 가중치를 사용했습니다. 실제 학습/추론 수행을 뜻하지 않습니다. 첫 테스트 실행에서 절대 경로 오류 문구에 대한 테스트 기대값 하나가 실제 오류와 달랐습니다. 기대값을 올바른 경로 거절 메시지로 수정한 뒤 전체 테스트를 다시 통과했습니다.

- 게임의 전체 허용 문자 집합·실제 폰트 fallback·정답 라벨의 정확성 확인.
- 실제 닉네임·게임 화면 수집 또는 사용.
- Electron Canvas/ONNX Runtime Web 실행, 앱 후처리·검색 연결, Stop/취소/롤백 검증.
- Windows native 학습 환경과 실장비 지연·메모리 측정.
- 독립 코드 리뷰, GitHub CI/PR, production 배포.

이 환경에는 PaddlePaddle·ONNX Runtime·Paddle2ONNX가 없습니다. ONNX/ONNX Runtime 패키지 설치를 시도했지만 네트워크 DNS 연결 실패로 설치되지 않았습니다. 설치 실패를 모델 실패나 미지원의 근거로 해석하지 않습니다.

학습에 필요한 승인된 전체 문자 목록, 실제 표시 조건의 이미지/정답, 가중치 및 GPU 환경을 제공받지 않았습니다. 따라서 결과 모델 파일과 실제 정확도 수치는 없습니다.
