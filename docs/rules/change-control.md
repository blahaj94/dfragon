# Change Control 안내

개발 절차와 권한 기준은 [개발 흐름](agent-workflow.md)에 통합했다. 과거 절차와 승인 이력은 Git 이력에 남아 있다.

## Approval evidence

현재 승인·적용 기준은 [판단과 권한](agent-workflow.md#판단과-권한)을 따른다. 이 이동은 제품별 착수·환경·실행 조건이나 proposed 제품 계약의 status를 바꾸지 않는다.

## Dependency 선택과 비용

[판단과 권한](agent-workflow.md#판단과-권한)과 [코드 재사용](code-reuse.md)을 따른다.
