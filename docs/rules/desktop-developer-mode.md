# Desktop 개발자 모드

설치한 DFRAGON 앱의 설정에서 개발자 모드를 켜고 끌 수 있다. 이번 사용자 요청은 기존 로컬 이미지·라벨·OCR 평가에 더해 파티 닉네임 네 위치의 실시간 미리보기, Print Screen 수집과 별도 정답 입력 화면을 채택한다. 이 변경의 사용자 merge 후 다른 작업에도 적용한다. 개발 실행 명령, DevTools 또는 인증 우회와 연결하지 않는다.

기본값은 꺼짐이고 로컬 설정을 다시 실행할 때 복원한다. 설정을 읽지 못하면 활성화하지 않는다. 이미지 조회·수집·라벨 변경·개발 캡처는 main에서 활성 상태와 등록한 main frame·document를 확인한다. renderer에 임의 파일 경로나 파일 시스템 접근 API를 제공하지 않는다. 모드를 꺼도 저장한 이미지와 정답은 삭제하지 않는다.

작업 공간을 열면 일반 파티 캡처를 중지하여 캡처·OCR 수명이 경쟁하지 않게 한다. 이미지 수집·파티원창 크롭·공대원창 크롭·정답 입력은 별도 탭으로 제공한다. 이미지 수집은 Windows의 실행 중인 DNF 창에서 실제 client 영역을 읽는다. 창 모드, 전체 창 모드에서 특정 client 해상도 제한 없이 검출하며 설정 파일 갱신 시점에 의존하지 않는다. 한 변 8192px, 총 33,000,000픽셀의 메모리 보호 한도는 유지한다. 일반 캡처와 공유하는 HP, MP 검출기의 해상도 제한 제거는 이 변경의 사용자 merge 후 적용한다. UI 배율은 화면의 파티 프레임 구조에서 계산하고 사용자에게 UI 비율이나 좌표를 입력받지 않는다. 파티 결성 중 HP·MP가 가득 찬 화면을 검출 대상으로 하며, 잔량이 줄어든 전투 상태의 검출은 지원 범위 밖이다. 장식이 사용자마다 달라지므로 HP·MP와 테두리를 기준으로 각 프레임을 독립 검출하고, 미검출 위치를 고정 간격으로 채우지 않는다. 프레임을 확인하지 못한 화면을 정상 크롭으로 저장하지 않는다.

이미지 수집 탭은 기본 0.5초 간격으로 네 닉네임 위치를 미리 보여주며 이 과정에서 파일을 저장하지 않는다. 캡처 주기 Select 입력에서 0.25초·0.5초·0.75초·1초를 선택하며, 작업 공간 안에서 세 수집 탭이 선택한 주기를 공유한다. 주기를 바꿔도 진행 중 캡처와 단축키 등록을 유지하고 중복 캡처를 시작하지 않는다. 이 주기 변경은 이번 사용자 요청 범위로 채택하며 사용자 merge 후 적용한다. 번호 1~4는 화면의 위치이며 특정 번호를 본인으로 단정하지 않는다. 각 위치는 기본 선택된 체크박스로 저장 포함 여부를 바꾸고, 선택하지 않은 위치도 흐리게 미리 보여준다. 수집 중 앱이 게임의 포커스를 빼앗거나 주기적으로 숨겨졌다 나타나지 않는다.

이번 후속 요청은 개발자 작업 공간에 이동 가능한 **파티참가인원 팝업**의 닉네임 크롭 탭을 추가하는 범위로 채택하며, 사용자 merge 후 적용한다. 일반 사용자 화면에는 추가하지 않는다. 공통 검출 함수로 위치·배율·참가 여부를 계산하고, 검출한 팝업과 닉네임 경계, 네 행의 원본 크롭을 보여준다. 전체 팝업이 client 안에 있고 외부 창에 가리지 않아야 한다. 검출하지 못하거나 후보가 모호하거나 탐색 한도를 넘으면 이전 미리보기를 비우고 저장하지 않는다.

파티원창의 네 행은 고정 위치다. 중간 참가자가 나가도 다른 행 번호를 당기지 않는다. 자물쇠만 있는 행도 빈 행이며 체크박스를 비활성화한다. 기본 선택은 네 행 모두이며, 빈 행이 되기 전의 선택은 유지하고 참가자가 다시 나타나면 복원한다.

이번 후속 요청은 같은 모양의 **12행 공대 상세 창**을 개발자 작업 공간의 공대원창 크롭 탭에 연결하는 범위로 채택하며 사용자 merge 후 적용한다. 공통 함수가 위치·배율·참가 여부를 검출하고 전체 팝업·닉네임 경계·1~12번 원본 크롭을 보여준다. 참가자가 나가면 아래 행이 위로 당겨지므로 번호와 저장 선택은 현재 화면 위치를 뜻하며 같은 캐릭터를 추적하지 않는다. 기본 선택은 12행 모두이고, 빈 행은 비활성화하되 기존 선택을 유지한다. 12행 창의 일부만 참가한 상태를 지원하며 별도 8인 레이드 레이아웃은 범위 밖이다. 미검출·모호한 후보·탐색 한도에서는 이전 미리보기를 비우고 저장하지 않는다. R/Y/G·싱글과 장비 점수는 기존 순수 함수의 객체 반환 범위를 유지하며 화면의 추가 필드·IPC·저장·자료실에 연결하지 않는다.

HUD·파티원창·공대원창의 선택 상태는 각각 유지한다. 키 안내와 현재 검출된 저장 대상 개수를 미리보기 위에 보여주며 키 안내는 화면 버튼이 아니다. 미리보기는 선택한 캡처 주기로 갱신하고 OCR을 실행하지 않는다. 세 수집 탭은 단일 단축키 수명을 공유하며 전환 시 이전 요청을 무효화한다.

Print Screen은 이미지 수집·파티원창 크롭·공대원창 크롭 탭이 열린 동안에만 등록하고 게임이 전경일 때 새 프레임의 선택된 크롭을 저장한다. 미리보기 캐시를 정답 데이터로 재사용하지 않는다. 빈 위치는 체크 여부와 관계없이 건너뛰고 선택한 위치 중 실제 검출된 크롭만 저장한다. 빈 위치가 체크되어 있어도 다른 검출된 선택 위치의 저장을 막지 않는다. 선택이 없거나 선택한 위치에서 검출된 크롭이 하나도 없으면 파일을 만들지 않고 이유를 알린다. 정답 입력 탭·일반 화면으로 이동하거나 개발자 모드를 끄거나 창을 종료하면 등록을 해제한다. 해제 뒤 늦게 완료된 요청이 수집을 다시 활성화하거나 새 저장을 시작하지 않는다. 저장 실패는 사용자에게 알린다. 던파만 관리자 권한으로 실행되어 단축키를 받을 수 없는 상태는 수집 활성화 전에 감지하고, 앱을 관리자 권한으로 다시 실행하도록 안내한다. 자동으로 권한을 올리거나 Windows 키 설정을 변경하지 않는다. Windows에서는 수집 수명에 한정한 키보드 훅으로 게임 전경의 Print Screen만 처리하고, 다른 앱의 입력은 그대로 전달한다. 전역 단축키 독점 등록으로 다른 앱의 Print Screen을 가로채지 않는다.

저장한 크롭은 필터나 리사이즈를 적용하지 않은 원본 픽셀이다. 모델 전처리는 평가용 사본에만 적용한다. 원본 이미지와 사용자 정답을 모델 출력으로 덮어쓰지 않는다. 수집 시 정답 입력이나 자동 OCR 평가를 요구하지 않는다.

이번 후속 요청은 세 수집 탭 상단에 Print Screen 처리 상태를 명확하게 표시하는 범위로 채택하며 사용자 merge 후 적용한다. 키 입력을 수락하면 캡처 중·로컬 저장 중·서버 업로드 중·서버 업로드 완료 또는 실패를 구분해 표시한다. 캡처 시도 번호와 시작 시각, 처리 중 경과 시간을 보여주며 5초 이상 걸리면 처리 중인 동안 추가 캡처가 저장되지 않음을 안내한다. 성공은 기존 서버 응답 검증을 통과한 경우에만 표시하고, 비로그인·권한·용량·결과 불명과 로컬 저장 결과를 구분한다. Main은 상태 변경만 신뢰한 main document에 즉시 전달하며 원본 픽셀·credential을 알림에 포함하지 않는다. 미리보기 지연 응답이 더 최근의 상태 알림을 덮어쓰거나 화면 이탈 뒤 알림을 반영하지 않는다. 기존 중복 수집 차단·취소·15초 전송 제한과 재시도 정책은 유지한다.

정답 입력 화면은 이미지 썸네일과 선택한 원본 확대, 미입력·완료·제외 필터를 제공한다. 사용자가 이미지마다 정답을 직접 입력한다. 새 입력이 비어 있으면 저장하지 않으며, 기존 데이터의 `null`(미작성)과 빈 문자열(명시적으로 빈 정답)은 구분해서 읽는다. 저장 성공 후에만 다음 이미지로 이동하고 실패하면 선택과 입력을 유지한다. 건너뛰기는 미작성 상태를 유지한다. 제외와 복원은 파일 삭제 없이 저장하고 다시 실행해도 복원한다. 이미지·탭을 전환해도 작업 공간 안의 미저장 입력은 유지한다.

저장 실패를 성공으로 표시하거나 입력을 없애지 않는다. 라벨·설정 저장은 기존 파일을 부분 JSON으로 덮어쓰지 않으며 새 샘플의 PNG·메타데이터 저장 실패를 성공한 샘플로 반환하지 않는다. 기존 샘플도 읽을 수 있어야 한다.

정답 입력 탭에서 [OCR 자료실 조회 계약](ocr-workspace.md#desktop-자료-조회평가)에 따라 서버 정답·크롭을 읽고 평가할 수 있다. 서버 자료는 로컬 편집 자료와 구분하며, 로컬 초안은 자료 위치를 전환해도 유지한다.

모델 결과와 정답은 구분한다. 기본 평가는 실제 OCR의 BT.601 회색 변환과 Otsu 반전 이진화를 공유하며, 원본 입력 평가에서는 이 단계를 생략할 수 있다. 두 옵션 모두 높이 48, 너비 최대 320으로 리사이즈하고 오른쪽을 정규화 값 0으로 패딩해 `[1, 3, 48, 320]` 입력을 사용한다. 닉네임 크롭은 유지하며 가우시안 블러, 추가 글자 경계 크롭, 상하 행 제거는 적용하지 않는다. 이 전처리 변경은 해당 PR의 사용자 merge 후 적용한다. 전처리를 바꾸면 이전 점수를 비운다. 완전 일치율·문자 오류율은 저장된 정답과 모델 원문을 기준으로 하며 실패·미작성·미평가를 성공 표본에 섞지 않고 별도 표시한다. 인식 신뢰도를 정답률로 표시하지 않는다. 평가 중지나 화면 종료 후 늦게 도착한 결과를 반영하지 않고 worker를 정리한다.

빌드 설정에서 호환되는 파인튜닝 ONNX와 문자 사전을 함께 선택할 수 있다. 파인튜닝 모델은 `dfragon-ocr-models`의 루트 ONNX와 사전 한 쌍을 submodule의 고정 커밋으로 가져오며, 모델 저장소의 새 커밋을 빌드 중 자동 추적하지 않는다. 실제 모델을 등록하기 전에는 기존 기본 모델을 유지한다. 일반 캡처와 개발자 평가는 같은 빌드에 포함된 모델을 사용한다. 설정 변경은 재시작 또는 재빌드로 적용하며 runtime 모델 선택, 다운로드, 학습 기능을 추가하지 않는다. 잘못된 파일이나 호환되지 않는 모델과 사전은 준비 단계에서 실패하고 기본 모델로 대체하지 않는다. 원본 vendor의 출처 검증은 유지하고, 선택한 파일의 실제 해시를 산출물에 기록한다. 이 범위는 해당 PR의 사용자 merge 후 적용하며 [모델 교체 안내](../../apps/desktop/README.md#파인튜닝-ocr-모델로-빌드하기)를 따른다.

모델 학습, 전체 파티 감지·연속 안정화의 성능 평가, 기존 Cropper 데이터·프로필 가져오기는 범위 밖이다. HUD·파티원창은 최대 네 위치, 공대원창은 최대 12행이며 위치와 실제 참가 여부를 구분한다. HUD의 세 번째·네 번째 프레임 실측 여부를 명시한다. Windows 실제 캡처·DPI·설치본 검증과 macOS의 UI·OCR 검증을 구분한다. 현재 저장 위치·제한·사용법은 [Desktop 안내](../../apps/desktop/README.md#개발자-모드)를 따른다.
