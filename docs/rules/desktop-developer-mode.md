# Desktop 개발자 모드

설치한 DFRAGON 앱의 설정에서 개발자 모드를 켜고 끌 수 있다. 이번 사용자 요청은 기존 로컬 이미지·라벨·OCR 평가에 더해 파티 닉네임 네 위치의 실시간 미리보기, Print Screen 수집과 별도 정답 입력 화면을 채택한다. 이 변경의 사용자 merge 후 다른 작업에도 적용한다. 개발 실행 명령, DevTools 또는 인증 우회와 연결하지 않는다.

기본값은 꺼짐이고 로컬 설정을 다시 실행할 때 복원한다. 설정을 읽지 못하면 활성화하지 않는다. 이미지 조회·수집·라벨 변경·개발 캡처는 main에서 활성 상태와 등록한 main frame·document를 확인한다. renderer에 임의 파일 경로나 파일 시스템 접근 API를 제공하지 않는다. 모드를 꺼도 저장한 이미지와 정답은 삭제하지 않는다.

작업 공간을 열면 일반 파티 캡처를 중지하여 캡처·OCR 수명이 경쟁하지 않게 한다. 이미지 수집과 정답 입력은 별도 탭으로 제공한다. 이미지 수집은 Windows의 실행 중인 DNF 창에서 실제 client 영역을 읽는다. 지원 범위는 창 모드·전체 창 모드와 1067×600~1920×1080이며 설정 파일 갱신 시점에 의존하지 않는다. UI 배율은 화면의 파티 프레임 구조에서 계산하고 사용자에게 UI 비율이나 좌표를 입력받지 않는다. 파티 결성 중 HP·MP가 가득 찬 화면을 검출 대상으로 하며, 잔량이 줄어든 전투 상태의 검출은 지원 범위 밖이다. 장식이 사용자마다 달라지므로 HP·MP와 테두리를 기준으로 각 프레임을 독립 검출하고, 미검출 위치를 고정 간격으로 채우지 않는다. 프레임을 확인하지 못한 화면을 정상 크롭으로 저장하지 않는다.

이미지 수집 탭은 1초 간격으로 네 닉네임 위치를 미리 보여주며 이 과정에서 파일을 저장하지 않는다. 번호 1~4는 화면의 위치이며 특정 번호를 본인으로 단정하지 않는다. 각 위치는 기본 선택된 체크박스로 저장 포함 여부를 바꾸고, 선택하지 않은 위치도 흐리게 미리 보여준다. 수집 중 앱이 게임의 포커스를 빼앗거나 주기적으로 숨겨졌다 나타나지 않는다.

Print Screen은 이미지 수집 탭이 열린 동안에만 등록하고 게임이 전경일 때 새 프레임의 선택된 크롭을 저장한다. 미리보기 캐시를 정답 데이터로 재사용하지 않는다. 선택이 없거나 선택한 위치 중 하나라도 검출되지 않으면 파일을 만들지 않고 이유를 알린다. 정답 입력 탭·일반 화면으로 이동하거나 개발자 모드를 끄거나 창을 종료하면 등록을 해제한다. 해제 뒤 늦게 완료된 요청이 수집을 다시 활성화하거나 새 저장을 시작하지 않는다. 저장 실패는 사용자에게 알린다.

저장한 크롭은 필터나 리사이즈를 적용하지 않은 원본 픽셀이다. 모델 전처리는 평가용 사본에만 적용한다. 원본 이미지와 사용자 정답을 모델 출력으로 덮어쓰지 않는다. 수집 시 정답 입력이나 자동 OCR 평가를 요구하지 않는다.

정답 입력 화면은 이미지 썸네일과 선택한 원본 확대, 미입력·완료·제외 필터를 제공한다. 사용자가 이미지마다 정답을 직접 입력한다. 새 입력이 비어 있으면 저장하지 않으며, 기존 데이터의 `null`(미작성)과 빈 문자열(명시적으로 빈 정답)은 구분해서 읽는다. 저장 성공 후에만 다음 이미지로 이동하고 실패하면 선택과 입력을 유지한다. 건너뛰기는 미작성 상태를 유지한다. 제외와 복원은 파일 삭제 없이 저장하고 다시 실행해도 복원한다. 이미지·탭을 전환해도 작업 공간 안의 미저장 입력은 유지한다.

저장 실패를 성공으로 표시하거나 입력을 없애지 않는다. 라벨·설정 저장은 기존 파일을 부분 JSON으로 덮어쓰지 않으며 새 샘플의 PNG·메타데이터 저장 실패를 성공한 샘플로 반환하지 않는다. 기존 샘플도 읽을 수 있어야 한다.

모델 결과와 정답은 구분한다. 기본 평가는 실제 OCR의 반전 회색조 전처리를 공유하며, 원본 입력 평가도 선택할 수 있다. 전처리를 바꾸면 이전 점수를 비운다. 완전 일치율·문자 오류율은 저장된 정답과 모델 원문을 기준으로 하며 실패·미작성·미평가를 성공 표본에 섞지 않고 별도 표시한다. 인식 신뢰도를 정답률로 표시하지 않는다. 평가 중지나 화면 종료 후 늦게 도착한 결과를 반영하지 않고 worker를 정리한다.

모델 학습, 전체 파티 감지·연속 안정화의 성능 평가, 기존 Cropper 데이터·프로필 가져오기는 범위 밖이다. 검출한 최대 네 위치와 실제 파티원 존재 판정을 구분하며 세 번째·네 번째 프레임의 실측 여부를 명시한다. Windows 실제 캡처·DPI·설치본 검증과 macOS의 UI·OCR 검증을 구분한다. 현재 저장 위치·제한·사용법은 [Desktop 안내](../../apps/desktop/README.md#개발자-모드)를 따른다.
