# Desktop 개발자 모드

설치한 DFRAGON 앱의 설정에서 개발자 모드를 켜고 끌 수 있다. 이번 사용자 요청은 앱 안의 테스트 이미지 생성·라벨링·기존 OCR 모델 평가와 이를 위한 로컬 저장·명시적 화면 캡처를 채택하는 범위다. 이 변경의 사용자 merge 후 다른 작업에도 적용한다. 개발 실행 명령, DevTools 또는 인증 우회와 연결하지 않는다.

기본값은 꺼짐이고 로컬 설정을 다시 실행할 때 복원한다. 설정을 읽지 못하면 활성화하지 않는다. 이미지 조회·수집·라벨 변경·개발 캡처는 main에서 활성 상태와 등록한 main frame·document를 확인한다. renderer에 임의 파일 경로나 파일 시스템 접근 API를 제공하지 않는다. 모드를 꺼도 저장한 이미지와 정답은 삭제하지 않는다.

작업 공간을 열면 일반 파티 캡처를 중지하여 캡처·OCR 수명이 경쟁하지 않게 한다. 개발 캡처는 사용자가 명시적으로 실행한 Windows 주 모니터 한 프레임을 대상으로 하며, 가져온 원본 프레임을 자동 저장하지 않는다. 사용자가 정한 크롭은 필터나 리사이즈 없이 저장하고 모델 전처리는 평가용 사본에만 적용한다. 원본 이미지와 사용자 정답을 모델 출력으로 덮어쓰지 않는다.

이미지별 정답에서 `null`은 미작성, 빈 문자열은 명시적으로 빈 정답이다. 저장 실패를 성공으로 표시하거나 입력을 없애지 않는다. 라벨·설정 저장은 기존 파일을 부분 JSON으로 덮어쓰지 않으며 새 샘플의 PNG·메타데이터 저장 실패를 성공한 샘플로 반환하지 않는다.

모델 결과와 정답은 구분한다. 기본 평가는 실제 OCR의 반전 회색조 전처리를 공유하며, 원본 입력 평가도 선택할 수 있다. 전처리를 바꾸면 이전 점수를 비운다. 완전 일치율·문자 오류율은 저장된 정답과 모델 원문을 기준으로 하며 실패·미작성·미평가를 성공 표본에 섞지 않고 별도 표시한다. 인식 신뢰도를 정답률로 표시하지 않는다. 평가 중지나 화면 종료 후 늦게 도착한 결과를 반영하지 않고 worker를 정리한다.

초기 적용 범위는 한 줄 텍스트 모델의 로컬 평가다. 전체 파티 감지·연속 안정화 평가, 모델 학습, 기존 Cropper 데이터 가져오기와 전역 단축키·프로필 이관은 후속이며 이번 결과로 완료를 주장하지 않는다. Windows 실제 캡처·DPI·설치본 검증과 macOS의 파일 기반 UI·OCR 검증을 구분한다. 현재 저장 위치·제한·사용법은 [Desktop 안내](../../apps/desktop/README.md#개발자-모드)를 따른다.
