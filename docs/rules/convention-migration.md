# Convention 이행 기록 안내

현행 작성 기준은 [convention.md](../../convention.md), 작업 단위·모델·리뷰·검증은 [개발 흐름](agent-workflow.md)과 [Testing](testing.md)에 통합했다. 특정 비교식의 형태를 맞추는 전수 이행, 숫자 기반 분할이나 별도 모델 mapping은 일상 개발 의무가 아니다.

기존 이행의 승인·실패·미완료 결과는 원래 Issue·PR과 Git 이력에 보존한다. [PR #150](https://github.com/blahaj94/ldb/pull/150), [Issue #158](https://github.com/blahaj94/ldb/issues/158), [PR #249](https://github.com/blahaj94/ldb/pull/249)의 기록을 이번 절차 정리로 성공·완료 처리하지 않는다. 재개를 요청받으면 같은 목적의 기존 결과와 유효한 검증을 이어 쓴다. 이 문서는 새 전수 교정이나 제품 계약 변경의 실행 지시가 아니다.
