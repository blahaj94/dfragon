# 제품 계획 안내

Discussion과 Project는 제품 계획을 정리하는 선택적 도구다. 현재 작업·기록·완료 기준은 [개발 흐름](agent-workflow.md#요청과-작업-단위)에 통합했다. 작은 요청을 시작하기 위해 계획 계층이나 실행 Issue를 새로 만들 필요는 없다.

기존 제품 계획·승인·미결정 조건과 진행 결과는 원래 위치에 보존한다. 계획 위치나 카드 상태를 바꿔도 사용자 실행 지시와 제품 검증 조건은 바뀌지 않는다. 이전 계획 이관의 근거는 [PR #235](https://github.com/blahaj94/ldb/pull/235), [PR #237](https://github.com/blahaj94/ldb/pull/237)과 Git 이력에서 찾을 수 있다.
