# DFragon Desktop UI 자산

- Pretendard Variable: Pretendard 1.3.9 npm 배포 원본의 `dist/web/variable/woff2/PretendardVariable.woff2`입니다. 출처: https://registry.npmjs.org/pretendard/-/pretendard-1.3.9.tgz , https://github.com/orioncactus/pretendard . SHA-256: `9599f12fd42fc0bce1cd50b47a0c022e108d7aa64dd0d1bb0ed44f3282d900b4`. Kil Hyung-jin의 글꼴이며 같은 패키지의 `dist/LICENSE.txt`인 OFL 1.1 전체 고지는 같은 폴더의 `FONT-LICENSE`에 있습니다.
- Barlow Condensed: Google Fonts 저장소 https://github.com/google/fonts 의 commit `60824dce48f7dd28fe7d65559f2da1f6e04e585b` `ofl/barlowcondensed/`에 있는 `BarlowCondensed-SemiBold.ttf`(SHA-256 `7b619d14bc2327509a9ef32b0890f709626f7ecc9ff61191c2a4314c5499d2d9`)와 `BarlowCondensed-Bold.ttf`(SHA-256 `e476562ec9c1e16cf16475895b511f08c804f438cc9a9f80a44ea50a0eeb5b65`), 글꼴 버전 1.408입니다. 원 저작물은 The Barlow Project Authors(https://github.com/jpt/barlow)의 글꼴입니다. fontTools 4.60.2로 기본 라틴 문자만 남겨 WOFF2로 바꾼 수정본이며, 명령은 `pyftsubset <원본 ttf> --unicodes=U+0020-007E --layout-features='*' --name-IDs='*' --flavor=woff2 --output-file=<출력 woff2>`입니다. 결과물 `BarlowCondensed-SemiBold.woff2`(SHA-256 `1489fb27387e88986cf63b0ba6c686387472e2de575fcf7b8c896a96ea4a248e`), `BarlowCondensed-Bold.woff2`(SHA-256 `b3b9717409b5239c09283b3c05a629c81bf297c947d88de199bf58b10152294b`)는 `apps/desktop/src/frontend/src/assets/fonts`에 있습니다. 같은 commit의 `OFL.txt`인 OFL 1.1 전체 고지는 같은 폴더의 `BARLOW-LICENSE`에 있습니다.
- 카메라, 테마 전환(해, 달), 명성(사람), 설정, 상세 열기, 캡처 창 선택(모니터, 체크, 화살표, 새로고침), 라이선스 목록의 오른쪽 화살표 SVG: Lucide 형태를 사용합니다. 출처: https://lucide.dev/icons . ISC와 Feather 파생 아이콘의 MIT 고지는 같은 폴더의 `LUCIDE-LICENSE`에 있습니다.
- 파티참가인원 검출 기준 헤더: 사용자가 제공한 던전앤파이터 화면에서 UI 0%의 네 열 제목, 구분선, 배경(368×17px)만 추출한 게임 UI 자산입니다. 권리는 NEOPLE/NEXON에 있으며 별도 오픈소스 라이선스를 부여하지 않습니다. 닉네임, 파티 제목, 플레이어 이미지는 포함하지 않습니다. `apps/desktop/src/backend/developer/participant-heading.png`에 무손실 PNG로 보관하며, 개발자 모드의 템플릿 비교에 사용합니다.
- 공대 상세 창 검출 기준 헤더: 같은 출처의 UI 0% 열 제목, 구분선, 배경(423×18px)만 추출한 게임 UI 자산입니다. 권리는 NEOPLE/NEXON에 있으며 별도 오픈소스 라이선스를 부여하지 않습니다. 닉네임, 공대 제목, 플레이어 이미지는 포함하지 않습니다. `apps/desktop/src/backend/lib/raid-heading.png`에 무손실 PNG로 보관하며, 개발자 모드와 일반 공대 캡처의 템플릿 비교에 사용합니다.
- 공대 상세 창 수치 열 제목 기준 이미지: 사용자가 제공한 던전앤파이터 1067×600 화면에서 UI 0%의 수치 열 제목 칸 두 개("명성", "장비 점수", 각 75×18px)만 추출한 게임 UI 자산입니다. 권리는 NEOPLE/NEXON에 있으며 별도 오픈소스 라이선스를 부여하지 않습니다. 닉네임, 공대 제목, 직업명, 플레이어 이미지는 포함하지 않습니다. `apps/desktop/src/backend/lib/raid-value-heading-fame.png`, `raid-value-heading-equipment-score.png`에 무손실 PNG로 보관하며, 공대 행 판독 오프라인 평가에 사용합니다.
- 공대 상세 창 수치 글자 기준 이미지: Windows 돋움 글꼴(`gulim.ttc` 글꼴 번호 2)을 dnf-ocr-synth(https://github.com/blahaj94/dnf-ocr-synth , commit `809df79`)로 UI 0% 크기에 렌더링한 `0`~`9`, 쉼표, 소수점, `K` 글자(높이 17px)입니다. 글꼴 파일은 포함하지 않으며 글꼴의 권리는 저작권자에게 있습니다. `apps/desktop/src/backend/lib/raid-value-glyphs.png`에 글자를 이어 붙인 무손실 PNG 한 장으로 보관하며, 공대 캡처의 수치 판독과 공대 행 판독 오프라인 평가에 사용합니다.
- 상세 창 스킬 탭의 스킬 아이콘: 던전앤파이터 한국 클라이언트의 NPK 이미지 팩에서 꺼낸 28×28 스킬 아이콘 2184개입니다(PVF 판본 `b2725b7c`, https://github.com/blahaj94/dnf-reverse-engineering 의 아이콘 층). 권리는 NEOPLE/NEXON에 있으며 별도 오픈소스 라이선스를 부여하지 않습니다. 원본 픽셀을 그대로 한 장에 모은 무손실 WebP sprite `packages/icons/skills.webp`로 보관하며, 상세 창 스킬트리의 칸과 설명 상자에 사용합니다.
- 카드 장비 면과 상세 창의 서약, 세트 아이콘: 같은 아이콘 층의 서약 아이콘 111개와 115 세트의 세트 아이콘 12개(28×28, 26×26 서약 아이콘은 28×28 칸 가운데에 둠)입니다. 권리는 NEOPLE/NEXON에 있으며 별도 오픈소스 라이선스를 부여하지 않습니다. 원본 픽셀을 그대로 한 장에 모은 무손실 WebP sprite `packages/icons/equipment.webp`로 보관하며, 세트와 서약 머리, 서약 본체 줄에 사용합니다.
- 상세 창 스킬 탭의 직업별 스킬 배치: dcalc(https://git.dnftools.com/dnftools/dcalc , commit `9e325bcab0ba83457c399921a3ac005713f5bdc4`)의 스킬 칸 좌표를 네오플 Open API의 직업, 스킬 목록과 대조한 행, 열 값입니다. dcalc의 라이선스는 확인하지 않았습니다. `packages/skill-layouts/layouts.json`에 보관합니다.
